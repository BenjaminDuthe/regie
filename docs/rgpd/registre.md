# Registre des traitements de regie

Registre tenu au titre de l'article 30 du RGPD. Squelette posé par l'histoire 1.1 : chaque histoire qui crée un traitement de données personnelles y ajoute sa fiche, dans la même modification.

## Responsable du traitement

- Organisme : _à compléter à l'installation_
- Contact : _à compléter_

## Fiches de traitement

Modèle d'une fiche :

| Rubrique | Contenu |
| --- | --- |
| Traitement | nom court |
| Finalité | pourquoi les données sont traitées |
| Base légale | contrat, consentement, obligation légale, intérêt légitime… |
| Personnes concernées | créatrices, membres, personnes filmées… |
| Données | catégories de données traitées |
| Destinataires | qui y a accès (aucun tiers par défaut) |
| Transferts hors UE | aucun |
| Durée de conservation | durée et événement de départ |
| Mesures de sécurité | cloisonnement, chiffrement, journal d'audit… |
| Histoire d'origine | numéro de l'histoire qui a créé le traitement |

_Aucun traitement de données personnelles à ce jour : la première page ne collecte rien._
