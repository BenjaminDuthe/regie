# regie

Régie de réseaux sociaux et générateur de vidéos verticales pour Établia, pilotée par Claude via MCP.

Le projet est au stade de la définition du produit : le PRD est en cours de rédaction, aucun code n'est encore écrit.

- `MANDAT.md` — l'énoncé de départ, mot pour mot, et son découpage en lots.
- `docs/planning/prd.md` — le document d'exigences produit (workflow BMAD, en cours).

Aucun secret n'est versionné : les clés d'API et les jetons vivent hors dépôt (variables d'environnement, coffre chiffré de l'application).
